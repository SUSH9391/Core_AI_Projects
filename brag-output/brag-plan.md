# Brag Plan

## Project Inspection Answers

1. **What is the app?**
   The app demonstrates core AI/ML implementations including digit classification with LeNet CNN and transfer learning for image classification using pretrained models.

2. **What is the funniest or most impressive claim?**
   Achieving 99% accuracy on MNIST digit recognition with a simple LeNet architecture, and demonstrating transfer learning that reduces training time from months to minutes by leveraging pretrained models.

3. **What is the visual hook?**
   The LeNet architecture diagram showing convolutional layers, alongside training accuracy plots that jump from random to 99%+ accuracy. For transfer learning, side-by-side images of bees and ants with classification confidence scores.

4. **What should be shown from the actual UI?**
   The notebook outputs: training logs showing loss decreasing, accuracy plots updating in real-time, and sample predictions on handwritten digits and bee/ant images.

5. **What is the shortest satisfying video?**
   18 seconds works: 3s hook, 5s LeNet training reveal, 6s transfer learning highlights, 4s punchline.

6. **What tone fits best?**
   - Tone preset: polished
   - Creative direction: clear educational demonstration of powerful ML techniques

7. **What should the audio feel like?**
   Warm corporate bed with light keyboard typing SFX for code scenes, and pleasant chimes when accuracy milestones are hit (90%, 95%, 99%).

8. **What should the share caption say?**
   From digit recognition to transfer learning: watch core ML techniques achieve 99% accuracy in seconds.

9. **What's the user flow worth showing?**
   Load dataset → define/train model → evaluate results: 
   - Load MNIST → watch LeNet train → see 99% accuracy
   - Load pretrained ResNet → fine-tune on bee/ant dataset → see classification results

## Storyboard

**Total Duration: 18 seconds**

### 0-3s: Hook
- Black screen with white text: "What if I told you..."
- Cut to: MNIST digit image being classified by LeNet
- Text overlay: "99% accuracy with 20 lines of code?"
- SFX: Subtle whoosh + keyboard click

### 3-8s: LeNet Reveal
- Show LeNet architecture diagram (layers lighting up sequentially)
- Transition to training loss/plummeting graph
- Accuracy counter ticking up: 10% → 50% → 80% → 99%
- Text overlay: "LeNet on MNIST: Handwritten digit recognition"
- SFX: Rising pitch as accuracy increases, chime at 99%

### 8-14s: Transfer Learning Highlights
- Split screen: Left (bee image), Right (ant image)
- Text overlay: "Transfer Learning: Knowledge transfer"
- Show ResNet18 model loading (progress bar)
- Quick fine-tuning simulation: Loss dropping rapidly
- Final classification: "BEE: 96% confidence" / "ANT: 92% confidence"
- Text overlay: "Months of training → Minutes of fine-tuning"
- SFX: Whoosh for model load, descending slide for loss, double chime for classifications

### 14-18s: Punchline/Outro
- Black screen with centered text: "Core AI Principles"
- Subtext: "From foundations to cutting-edge"
- Logo/text: "Core_AI_Projects" (small bottom corner)
- SFX: Soft landing chord

## Music Cue Guidance
- Track: Upbeat corporate motivational (120 BPM)
- Cue 1 (0s): Start on downbeat
- Cue 2 (3s): Build with additional pads for LeNet section
- Cue 3 (8s): Rhythm elements kick in for transfer learning section
- Cue 4 (14s): Simplify to just melody for outro
- End on resolved chord

## Visual Style Notes
- Color palette: Blues (#2563eb) and grays from notebook outputs
- Font: Monospace for code, sans-serif for body (Courier New / Inter)
- Transitions: Clean cuts and subtle fades
- Text appearance: Typewriter effect for code, fade-in for explanations
